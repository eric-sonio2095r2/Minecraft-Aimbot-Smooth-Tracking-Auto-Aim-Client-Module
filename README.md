# Minecraft Aimbot

**Smooth Tracking & Auto Aim Client Module for Minecraft 1.20 – 1.21**

This is a full client-side Minecraft aimbot with adaptive smooth tracking and precise auto aim.  
Built as a clean modular system with full configuration support and low performance impact.

---

### What this is

A complete Minecraft aimbot that provides:
- Adaptive auto aim  
- Smooth tracking system  
- Fully adjustable response curves  
- Low CPU/GPU usage  
- Open and readable source structure  

Supports both Forge and Fabric.

---

### Features

- Adaptive auto aim engine  
- Smooth tracking curves  
- Configurable speed & smoothness  
- FOV and priority settings  
- Modular design  
- Ready for 1.20.x and 1.21.x

### Configuration

All settings are stored in `config/default.json`:

- Aim speed  
- Smoothness multiplier  
- FOV limits  
- Target priority
